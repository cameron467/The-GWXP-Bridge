# Open Problems and Falsification Targets

The project is most useful if the remaining failure conditions are explicit.

## A. One-parent-Hamiltonian integration

The decisive missing theorem is:

```text
one microscopic finite relational Hamiltonian
        |
        v
stable thermodynamic phase
        |
        +--> nondegenerate 3D relational geometry
        +--> spatial first-class constraints
        +--> scalar/refoliation first-class constraint
        +--> HDA with same Q^ij
        +--> exactly two z=1 tensor modes
        +--> no scalar/vector/aether contamination
```

A model that merely places GR stabilizers in the parent Hamiltonian does not count.

## B. Global graph-phase theorem

Find either:

1. a proof that the frozen resource/capacity functional has a 3D thermodynamic minimizer in the relevant class, or
2. a genuine fixed-scale non-3D infinite graph with lower energy density.

Either result would materially sharpen the programme.

## C. First-class vs. gapped sector

The current all-reflection phase has a separated fiber-odd band.

This is not yet a proof of gauge redundancy.

The next test must distinguish:

```text
massive physical scalar
```

from

```text
first-class scalar / refoliation constraint.
```

## D. TT-mode integration

Demonstrate the two physical tensor modes in the same autonomous phase, not in a separate quadratic compatibility model.

Required checks:

- exactly two soft tensor modes;
- `omega ~ c k`;
- no scalar/vector branch;
- same emergent `Q^{ij}` in dispersion and HDA closure.

## E. Nonlinear closure

The continuum benchmark currently tests the leading normal-normal structure.

A stronger result would test:

- mixed spatial/normal brackets;
- Jacobi/associativity at the effective level;
- nonlinear state dependence of `Q^{ij}`;
- absence of anomalies under coarse-graining.

## F. Newton coupling

The project has demoted “bits per site determine `G`.”

A real microscopic theory should compute the Einstein-response coefficient

```math
c_R=\frac1{16\pi G}
```

from the phase.

## G. Strong-field bridge

After the bulk gravitational phase is under control:

- derive the moving-code horizon variable;
- derive the MOTS cross-Jacobian from the same parent;
- test the fold;
- test zero static Love plus dynamical absorption;
- eventually compare black-hole entropy coefficient with the independently derived `c_R`.

## Explicit falsification criteria

GWXP should be substantially weakened if:

- the autonomous phase always retains an extra scalar;
- the HDA structure function differs from the propagation metric;
- a preferred microscopic foliation survives in the IR;
- tensor dispersion is generically `z != 1`;
- 3D selection requires a hidden target-lattice term;
- the apparent 3D phase disappears under larger independent simulations;
- the full constraint structure requires explicit GR stabilizers;
- nonlinear closure fails or becomes anomalous.
