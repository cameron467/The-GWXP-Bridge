# Prior-Art Addendum — Natural Emergence Update

This addendum supplements the repository's existing citations.

The purpose is to define the boundary of the new Natural Emergence claims, not to claim novelty.

## Dynamical graphs and emergent locality

**T. Konopka, F. Markopoulou, S. Severini**,  
*Quantum graphity: A model of emergent locality*,  
Phys. Rev. D **77**, 104029 (2008).  
DOI: `10.1103/PhysRevD.77.104029`

Quantum Graphity already studies a permutation-invariant dynamical graph whose low-energy phase can become ordered, local and low-dimensional.

Therefore GWXP should **not** claim that dynamical graphs, permutation symmetry breaking or low-dimensional geometrogenesis are new ideas.

An earlier version is:

**T. Konopka, F. Markopoulou, L. Smolin**,  
*Quantum Graphity*, arXiv:`hep-th/0611197` (2006).

## Graph communicability

The use of a matrix exponential

```math
[e^{\beta A}]_{ij}
```

as an all-walk communicability object is standard in network theory.

Relevant literature includes work by **Ernesto Estrada and Naomichi Hatano** on graph communicability and subgraph centrality, and:

**E. Estrada**,  
*The communicability distance in graphs*,  
Linear Algebra and its Applications **436** (2012), 4317–4328.  
DOI: `10.1016/j.laa.2012.01.017`

Accordingly, the matrix exponential itself is not a GWXP invention.

The narrower object under investigation is the **competition between all-walk communicability and convex finite link capacity as a dimension-selecting energetic mechanism**.
