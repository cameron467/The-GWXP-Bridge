# Archive

These files preserve earlier checkpoints and continuation bundles for provenance.

They contain superseded code, states, and interpretations and therefore **must not override** the frozen candidate or final-pass status files at the repository root / `docs/`.

Important reasons to keep them include:

- documenting the discovery of hidden proposal/locality assumptions;
- preserving failed parameter regions and adversaries;
- allowing reviewers to audit when claims were corrected rather than silently rewritten;
- retaining intermediate code/states that may be useful for independent forensic reproduction.

For current claims, use `README.md`, `02) Project Status - 2026-09-29.md`, `04) Known Issues and Corrections - 2026-09-29.md`, and `docs/01) Frozen Candidate Parent - 2026-09-29.md`.
